# ForceVera Website

Responsive multi-page marketing website and CRO landing page for ForceVera.

## Pages
- `index.html` — primary CRO / SEO landing page
- `features.html`
- `solutions.html`
- `pricing.html`
- `resources.html`

## Design direction
Dark navy hero, bright blue/cyan ForceVera branding, clean white content sections, compact operational feature cards, industry-specific sections, integration strip, SaaS plans, responsive mobile layout and persistent mobile conversion CTA.

## Assets
Brand assets are under `assets/`. The web logo and mobile app icon are transparent images with cropped variants for cleaner placement.

## Notes
The hero currently references a free Unsplash security image remotely. Replace it with a locally licensed production photo if you want the project to be fully self-contained.
